# CV Site

This repository hosts my personal CV website.

The site serves as a central place to share my **resume, professional experience, and personal projects**. It also includes links to projects and other work that showcase my interests, skills, and experience across data analytics, programming, finance, and related areas.

This repository is primarily intended to support the website itself rather than serve as a standalone software project.

## Contents

* **Resume / CV** — Professional experience, education, and skills
* **Personal Projects** — Links and information about projects I have worked on
* **Project Resources** — Links to relevant repositories, demos, and other materials
